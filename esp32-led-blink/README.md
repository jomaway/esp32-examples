# ESP32 LED blink example

The hello-world of microcontrollers. Simply blink an led.

## New Concepts

- `setup()` and `loop()` functions.
- `#include` Header files.
- `constexpr` compile time variables as modern c++ alternative to `#define`
- `pinMode()`, `digitalWrite()` and `delay()` functions
